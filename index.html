Virtual Mouse

This project creates a Virtual Mouse allowing users to control their computer cursor using hand gestures captured by a webcam. It leverages MediaPipe to detect hand landmarks and PyAutoGUI to map the index fingertip movement to screen coordinates. A left-click is performed by touching the index finger and thumb tips together, with built-in features to prevent accidental double-clicking and PyAutoGUI fail-safe errors.
